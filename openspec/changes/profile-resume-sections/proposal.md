# Proposal: Profile sections, experience timeline, and resume downloads

## Why

The home page currently presents only the profile, projects, and blog. Adding professional experience, certification, skills, and an ATS-friendly resume makes the portfolio useful for both readers and recruiters.

## What changes

- Add bilingual Experience, Certifications, and Skills sections after About.
- Render Experience as a responsive local shadcn-style vertical timeline.
- Add navigation and scroll tracking for the new sections.
- Add the Claude Certified Architect - Foundations credential with its Credly link.
- Add a public general resume download and keep an Entropy-specific resume private.

## Out of scope

- The existing `circuit-portfolio` redesign proposal.
- Publishing the Entropy-specific resume.
- Adding a new UI framework or external runtime dependency.
