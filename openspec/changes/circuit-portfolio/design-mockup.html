Reading the sheets: the hub replaces a navbar with a flow diagram, bookended by Start (identity) on the left and Contact on the right — every section's path leads somewhere, ordered by importance: Experience first, then Projects, Skills, and Blog last (it's the one still deferred). Experience is a milestone trace, reusing the board's copper-line vocabulary for a career timeline instead of a product. Projects and Skills both use four-or-five-part breakdowns but for different jobs, so they're drawn two different ways: Projects is a board you route through to browse work (Electronics, Software, AI/ML, Gamedev); Skills is a left-to-right system pipeline you scan for tools (Electronics, Frontend, Backend, Infrastructure, AI) — closer to how the tech itself actually connects. Blog is intentionally inert until there's real writing to show.
